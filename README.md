
# Hello, I'm Xander! 👋

CS Senior @ Miami University and SWE Intern @ Kroger. I like building small, focused tools that people can actually use, while keeping the data in their hands. When building, I mainly focus on a few things: simplification, accessibility, and making things that work and feel nice to use.

## What I'm Currently Building

### **[home-tools](https://github.com/XanderOnGithub/home-tools)**

Self-hosted apps built to work seamlessly in my household. Stored in plain JSON on my ZimaOS server.

- **Fitness:** exercises, plans, and routines, plus a view of which muscles were worked and which need recovery
- **Game servers:** a control panel for our containerized Minecraft and Valheim servers
- **Discord bot:** lets friends check on and restart the servers themselves

**Built with:** Go, Svelte 5, TypeScript, Docker, Caddy, GitHub Actions → GHCR → ZimaOS

### **[moss](https://github.com/XanderOnGithub/task-manager)**

Personal project management software, created to learn how to use Claude more effectively. Stored in JSON on the device

- **Project Management:** Has list & board views to keep track of tasks
- **Documentation:** Has a rich-text Markdown editor and page structure for documentation
- **Designed by Me:** I designed every aspect of this program. I've been thinking about this project for over a year, wanting to make a project management software without using Agile terms.

**Built with:** TypeScript, React, Rust, Tauri, GitHub Actions

## How I Work With AI

[![Claude Code](https://img.shields.io/badge/Claude_Code-D97757?logo=claude&logoColor=white)](https://claude.ai/code)

I use agentic coding tools, mainly Claude, but the application is still mine. I know how I want software to work and feel, and I write a detailed plan before any agent touches the code. My projects include an `AGENTS.md` that describes what I want, how I want it built, and what it takes for it to work.

- **I write:** the design, the front-end layouts, and as much code as I can (hand-coding is still a valuable skill)
- **Agents help with:** boilerplate and heavier logic, built against my design, organization, and spec
- **Git:** Claude helps me write commits and PRs, which keeps my history consistent and has taught me better Git habits
- **Every change:** goes through automated checks and gets reviewed by me against the spec before it ships
