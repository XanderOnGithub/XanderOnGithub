
# Hello, I'm Xander! 👋

CS Senior @ Miami University and SWE Intern @ Kroger. I like building small, focused tools that people can actually use, while keeping the data in their hands. When building, I mainly focus on a few things: Simplification, Accessibility, and just making things that work and feel nice to use.

## What I'm Currently Building

### **[home-tools](https://github.com/XanderOnGithub/home-tools)**

Self-Hosted apps built to work seamlessly in my household. Stored in plain JSON on my ZimaOS Server.

- **Fitness:** exercises, plans, and routines, plus a view of which muscles were worked and which need recovery
- **Game servers:** a control panel for our containerized Minecraft and Valheim servers
- **Discord bot:** lets friends check on and restart the servers themselves

**Built with:** Go, Svelte 5, TypeScript, Docker, Caddy, GitHub Actions → GHCR → ZimaOS
